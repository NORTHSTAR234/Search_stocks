# Halal report archive

These security folders contain archived Search_stock reports for tickers whose **latest report as of 7 November 2026** records a Musaffa HALAL classification with a screening date meeting the four-calendar-month recency gate. These are historical report classifications, **not perpetual compliance guarantees**. Recheck Musaffa on each new research run. Keep all reports for the same ticker together to preserve comparisons.

Tickers: AAPL, AMAT, AMD, CSCO, CVX, HD, JNJ, KO, LLY, MA, MU, NVDA, ORG, PG, TSLA, V, XOM.

Report format: `halal/<TICKER>/<TICKER>_YYYY-MM-DD_HH-mm-ssZ.md`.
